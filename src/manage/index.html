Import rankings
Import CSV or JSON with an explicit source and metric edition. Journal rows require a valid ISSN; conference rows require their full name. Imports replace the same identity/metric/year and invalidate the resolution cache.
Download CSV headers · Journal fields: jcr, cas, category, if, top · Conference fields: ccf, core. Common fields: type, name, abbr, issn, year, source.


Optional DeepSeek fallback
deepseek-flash · Thinking disabled · Maximum 512 output tokens per attempt. Used only after ordinary metadata lookup fails. The model suggests a search query; provider records must verify the original publication before badges are added.


Missing metadata & rankings
Recognized venues may still lack ratings. Crossref and OpenAlex do not supply JCR, CAS, CCF or CORE editions. Import the relevant rankings, then retry records. Known Non-TOP and unranked entries are preserved explicitly.
